# Portfolio Optimization & Risk Analysis

## Overview

This project uses Python to analyze and optimize a diversified stock portfolio using historical market data and Modern Portfolio Theory.

The project evaluates portfolio risk and return, calculates optimal portfolio weights, and compares portfolio performance with the NIFTY 50 benchmark.

## Objectives

- Analyze historical stock price data
- Calculate stock and portfolio returns
- Measure portfolio volatility and risk
- Analyze correlations between stocks
- Optimize portfolio weights
- Evaluate risk-adjusted performance using the Sharpe Ratio
- Visualize the efficient frontier
- Compare portfolio performance with the NIFTY 50 benchmark

## Methodology

The project follows these main steps:

1. Collect historical stock price data
2. Calculate daily returns
3. Annualize returns and volatility
4. Calculate the covariance matrix
5. Generate portfolio combinations
6. Calculate portfolio return, volatility and Sharpe Ratio
7. Identify the optimized portfolio
8. Visualize the efficient frontier
9. Compare portfolio performance against the NIFTY 50
